# 📚 國中部申請入學審查資料系統

## 🎯 專案概述
Google Apps Script 開發的線上申請系統，包含學生端和後台管理系統。

## 📊 開發進度

- [x] Phase 1: 認證系統 + 密碼管理

- [x] Phase 4: 特殊表現模組（10筆）
- [x] Phase A: 後台登入系統

### 🚧 開發中

## 🔧 技術棧
- **前端**: HTML/CSS/JavaScript
- **後端**: Google Apps Script (GAS)
- **資料庫**: Google Sheet
- **檔案儲存**: Google Drive

| 檔案 | 說明 |

| `BasicInfo.html` | 學生基本資料頁面 |
