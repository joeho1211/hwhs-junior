## 📋 專案概述

本系統是一套完整的申請入學審查資料管理平台，分為「學生端」與「後台管理端」兩大部分。學生可透過學生端上傳個人資料、成績及特殊表現；後台人員則可進行資料審查與管理。

### 🎯 系統目標

- ✅ 提供安全的學生資料上傳平台
- ✅ 支援多學期成績管理（五年級上、五年級下、六年級上）
- ✅ 記錄多元表現資料（最多10筆）
- ✅ 完整的操作日誌與版本控制
- ✅ 後台資料審查與管理功能

## 🚀 快速開始

### 前置條件

- Google Apps Script 專案
- Google Sheet（資料儲存）
- Google Drive（檔案儲存）
- 現代瀏覽器（Chrome、Firefox、Safari 等）

### 部署步驟

#### Step 1: 建立 Google Sheet
1. 開啟 [Google Sheet](https://sheets.google.com)
2. 建立新的 Google Sheet
3. 複製 Sheet ID（URL 中 `/d/` 後的字串）

#### Step 2: 建立 Google Drive 資料夾
1. 開啟 [Google Drive](https://drive.google.com)
2. 建立新資料夾用於存放學生上傳的檔案
3. 複製資料夾 ID（URL 中 `/folders/` 後的字串）

#### Step 3: 建立 Google Apps Script 應用
1. 進入 [Google Apps Script](https://script.google.com)
2. 點擊「+ 新增專案」
3. 將所有程式碼複製到編輯器中

#### Step 4: 設定全域變數
在 `Code.gs` 頂部修改以下變數：

```javascript
const SHEET_ID = "您的Google Sheet ID";
const FOLDER_ID = "您的Google Drive資料夾ID";
const SENDER_EMAIL = "school@example.com"; // 學校信箱

####Step 5: 初始化系統
執行 setupSystem() 函數來建立所有必要的工作表

#### Step 6: 部署應用
點擊「部署」→「新部署」
類型選擇「Web 應用程式」
執行身份：選擇你的帳號
有權限的使用者：「所有人」
複製部署 URL

#### ✨ 主要功能
📖 學生端功能
1. 登入系統 [Phase 1]
帳號：參加證號
密碼：身分證10碼 + 生日月日4碼
密碼修改與忘記密碼功能
2. 基本資料 [Phase 2]
填寫姓名、身分證字號、校名等基本資訊
修改登入密碼
截止時間內可重複修改
3. 成績上傳 [Phase 3]
3個學期：5年級上、5年級下、6年級上
11個科目：語言領域（3種）、數學、社會、自然、藝術（3種）、健體（2種）
等第系統：優、甲、乙、丙、丁
檔案上傳：PDF 或圖檔（上限 5MB）
截止時間內可重複上傳修改
4. 特殊表現 [Phase 4]
最多10筆資料紀錄
類別選擇、活動名稱、名次、日期、發證單位
檔案上傳（PDF 或圖檔）
可刪除單筆資料
截止時間內可重複修改

#### 🔒 安全特性
✅ 密碼加密：採用 HMAC-SHA256 加密算法
✅ 版本控制：完整的修改紀錄與版本追蹤
✅ 操作日誌：所有後台操作都有紀錄
✅ 檔案驗證：格式、大小上限檢查
✅ 截止時間控制：超過截止時間自動鎖定
